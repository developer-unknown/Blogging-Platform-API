1. Clone the repository
2. Install the dependencies
```
yarn install
```
3. Clone the .env.template file and rename it to .env
4. Change environment variables
5. Raise the project
```
yarn start:dev
```
6. Run the SEED
```
http://localhost:3000/api/seed
```
